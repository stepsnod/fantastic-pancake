Every item on this site is a passage from the book that belongs to somebody else and gets read aloud in the audiobook. For each one there are two questions: does it need permission at all, and if so, where has that got to.

The one thing worth knowing before you start.

Public domain means copyright has expired and anyone may use the work freely. It is decided by age. Shakespeare, the King James Bible and Emily Dickinson are all public domain, and there is nothing to ask.

But an old work can still carry a new copyright. Dante died in 1321 and Catullus two thousand years ago — yet the English translation quoted in this book is a separate, recent work with a copyright of its own. About a sixth of this list is here for exactly that reason. So whenever you mark something public domain, please say why in the box: published before 1930, author died in such a year. That one habit is what stops “it’s old, so it’s free”.

There is a third idea, fair use, which sometimes allows short quotation without asking. It is a defence argued case by case rather than a category a passage belongs to, so it is deliberately not one of the options here. If counsel wants to rely on it, the note box is the place to say so.
